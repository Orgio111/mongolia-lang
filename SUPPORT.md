# Mongolia project support

For installation failures include your OS, CPU architecture, package filename, SHA-256 result and exact failing command. For compiler issues include mn --version, a minimal .mn input, diagnostic language, exit status and expected output. Use the repository's bug template once its issue tracker is opened. For installation, shape errors and language limits start with INSTALLATION_GUIDE.md and docs/USER_GUIDE.md. Sensitive reports follow SECURITY.md. The source kit includes no hosted support service or guaranteed response time.
